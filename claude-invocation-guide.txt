================================================================================
                     Claude CLI 调用方法详解
                    Hermit-Claw 容器内 AI 助手调用技术文档
================================================================================

本文档详细说明如何在 Node.js 服务器中调用 Claude CLI（claude 命令），
实现与 AI 助手的交互，包括 API 密钥配置、进程管理、流式响应处理等。

================================================================================
一、核心原理概述
================================================================================

Claude CLI 是 Anthropic 提供的命令行工具，通过 spawn 子进程方式调用。
主要特点：
- 使用子进程（child_process.spawn）启动 claude 命令
- 通过临时文件传递用户消息和上下文
- 支持 SSE（Server-Sent Events）流式响应
- 通过环境变量传递 API 密钥和配置

================================================================================
二、API 密钥配置方法
================================================================================

Claude CLI 不直接接受密钥参数，而是通过环境变量读取配置。

2.1 环境变量配置

必需的环境变量：
- ANTHROPIC_AUTH_TOKEN     : API 密钥（格式：sk-xxxx...）
- ANTHROPIC_API_KEY        : 同上，兼容另一种命名
- ANTHROPIC_BASE_URL       : API 端点（默认 https://api.anthropic.com）
- ANTHROPIC_MODEL          : 模型名称（可选，默认 claude-sonnet-4-20250514）
- ANTHROPIC_DISABLE_PREFLIGHT : 设为 '1' 跳过预检

示例配置：
```javascript
const env = {
  ANTHROPIC_AUTH_TOKEN: 'sk-xxxx...',           // API 密钥
  ANTHROPIC_BASE_URL: 'https://api.anthropic.com', // API 端点
  ANTHROPIC_DISABLE_PREFLIGHT: '1',              // 跳过预检
  PATH: process.env.PATH || '/usr/bin:/bin:/usr/local/bin'
};
```

2.2 从配置文件读取密钥

可以通过读取 Claude 配置文件获取密钥：

```javascript
function getClaudeRuntimeEnv() {
  const result = {};
  const home = process.env.HOME || '';
  const configPaths = [
    home ? path.join(home, '.claude', 'config.json') : '',
    '/agent-config/config.json'
  ].filter(Boolean);

  for (const configPath of configPaths) {
    const config = readJsonFile(configPath);
    const current = config && config.claude && config.claude.current;
    const provider = current && config.claude.providers && config.claude.providers[current];
    const env = provider && provider.settingsConfig && provider.settingsConfig.env;
    if (env) Object.assign(result, env);
  }

  return result;
}
```

配置文件结构（~/.claude/config.json）：
```json
{
  "claude": {
    "current": "default",
    "providers": {
      "default": {
        "settingsConfig": {
          "env": {
            "ANTHROPIC_AUTH_TOKEN": "sk-xxxx...",
            "ANTHROPIC_BASE_URL": "https://api.anthropic.com"
          }
        }
      }
    }
  }
}
```

================================================================================
三、启动 Claude CLI 进程
================================================================================

3.1 基础调用方式

使用 child_process.spawn 启动 claude 命令：

```javascript
const { spawn } = require('child_process');

const args = [
  '--dangerously-skip-permissions',  // 跳过权限确认
  '--continue',                       // 继续之前的会话
  '-p',                               // print 模式（非交互）
  tmpFile                             // 临时文件路径（包含消息内容）
];

const claude = spawn('claude', args, {
  stdio: ['ignore', 'pipe', 'pipe'],  // 忽略 stdin，捕获 stdout 和 stderr
  env: env
});
```

3.2 关键参数说明

| 参数                      | 说明                                   |
|--------------------------|----------------------------------------|
| --dangerously-skip-permissions | 跳过交互式权限确认（自动化必需）   |
| --continue               | 继续之前的会话上下文                   |
| -p / --print             | 打印输出模式（非 TUI 交互）             |
| -m / --model             | 指定模型（可选）                       |

五、流式响应处理（SSE）

5.1 监听 stdout 流

```javascript
let stdout = '';
let stderr = '';

claude.stdout.on('data', (data) => {
  const chunk = data.toString();

});

claude.stderr.on('data', (data) => {
  const chunk = data.toString();
  stderr += chunk;
  // 日志记录 stderr 内容
});
```

5.2 SSE 消息格式

```javascript
function sendSSEMessage(res, type, content) {
  res.write('data: ' + JSON.stringify({type: type, content: content}) + '\n\n');
}

// 消息类型：
// - 'chunk': 数据块
// - 'complete': 完成，携带 {dialogId, response}
// - 'error': 错误信息
```

六、进程管理与错误处理
================================================================================

6.1 超时处理

```javascript
const TIMEOUT_MS = 1200000; // 20分钟

let killed = false;
let timeoutId = setTimeout(() => {
  if (!killed && claude && !claude.killed) {
    killed = true;
    claude.kill('SIGTERM');
    sendSSEMessage(res, 'error', '请求超时（1200秒），请重试');
    res.end();
  }
}, TIMEOUT_MS);
```

6.2 进程关闭处理

```javascript
claude.on('close', (code) => {
  clearTimeout(timeoutId);
  if (killed) return;
  killed = true;

  // 清理临时文件
  try { fs.unlinkSync(tmpFile); } catch(e) {}

  if (code === 0) {
    // 成功：保存响应
    dialog.aiResponse = stdout.trim();
    saveDialog(dialog);
    sendSSEMessage(res, 'complete', JSON.stringify({dialogId, response: stdout.trim()}));
  } else {
    // 失败：记录错误
    dialog.aiResponse = '（错误：' + (stderr || 'Claude进程退出，代码: ' + code) + '）';
    saveDialog(dialog);
    sendSSEMessage(res, 'error', 'Claude错误: ' + (stderr || '进程退出，代码: ' + code));
  }
  res.end();
});
```

6.3 进程启动错误

```javascript
claude.on('error', (err) => {
  clearTimeout(timeoutId);
  killed = true;
  logClaudeDebug('spawn:error', {error: err.message});
  try { fs.unlinkSync(tmpFile); } catch(e) {}
  sendSSEMessage(res, 'error', '启动Claude失败: ' + err.message);
  res.end();
});
```

================================================================================
七、完整调用示例
================================================================================

```javascript
const { spawn } = require('child_process');
const fs = require('fs');
const path = require('path');

// 获取运行时环境变量（包含 API 密钥）
function getClaudeRuntimeEnv() {
  const result = {};
  const home = process.env.HOME || '';
  const configPath = path.join(home, '.claude', 'config.json');
  try {
    const config = JSON.parse(fs.readFileSync(configPath, 'utf8'));
    const current = config?.claude?.current;
    const provider = config?.claude?.providers?.[current];
    const env = provider?.settingsConfig?.env;
    if (env) Object.assign(result, env);
  } catch (e) {}
  return result;
}

// 调用 Claude CLI
function callClaudeCLI(userMessage, res) {
  // 生成临时文件
  const tmpFile = '/tmp/claude_msg_' + Date.now() + '.txt';
  fs.writeFileSync(tmpFile, userMessage, 'utf8');

  // 构建环境变量
  const env = {
    ...process.env,
    ...getClaudeRuntimeEnv(),
    ANTHROPIC_DISABLE_PREFLIGHT: '1'
  };

  // 启动进程
  const claude = spawn('claude', [
    '--dangerously-skip-permissions',
    '--continue',
    '-p',
    tmpFile
  ], {
    stdio: ['ignore', 'pipe', 'pipe'],
    env: env
  });

  let stdout = '';
  let stderr = '';

  // 处理输出流
  claude.stdout.on('data', (data) => {
    const chunk = data.toString();
    stdout += chunk;
    res.write('data: ' + JSON.stringify({type: 'chunk', content: chunk}) + '\n\n');
  });

  claude.stderr.on('data', (data) => {
    stderr += data.toString();
  });

  // 处理关闭
  claude.on('close', (code) => {
    fs.unlinkSync(tmpFile);  // 清理临时文件
    if (code === 0) {
      res.write('data: ' + JSON.stringify({type: 'complete', response: stdout.trim()}) + '\n\n');
    } else {
      res.write('data: ' + JSON.stringify({type: 'error', message: stderr}) + '\n\n');
    }
    res.end();
  });

  // 处理错误
  claude.on('error', (err) => {
    try { fs.unlinkSync(tmpFile); } catch(e) {}
    res.write('data: ' + JSON.stringify({type: 'error', message: err.message}) + '\n\n');
    res.end();
  });
}
```

十一、方案演进历史与对比
================================================================================

本项目从 Hermit-Claw 容器环境出发，采用 Claude CLI 方案。以下记录
技术方案的演进历程以及与 SDK 方案的对比。

11.1 项目技术方案演进

| 阶段 | 时间 | 方案 | 特点 |
|------|------|------|------|
| 初期 | 2026-04 | Claude CLI（基础版） | 无 --continue，无 tmpFile，超时 60 秒 |
| 中期 | 2026-04 | Claude CLI（增强版） | 添加 --continue，tmpFile，超时 120 秒 |
| 稳定版 | 2026-05 | Claude CLI（生产版） | 完整 SSE 流式，20 分钟超时，对话持久化 |

11.2 早期版本的 Claude CLI 调用（无上下文版）

项目早期使用更简单的调用方式，不传递历史上下文：

```javascript
function callClaudeBasic(userMessage, onResponse) {
  const systemPrompt = getSkillContent();
  const fullMessage = systemPrompt ? `${systemPrompt}\n\n---\n\n${userMessage}` : userMessage;

  const tmpFile = path.join(os.tmpdir(), 'claude_msg_' + Date.now() + '.txt');
  fs.writeFileSync(tmpFile, fullMessage, 'utf8');

  const env = {
    ...process.env,
    ANTHROPIC_DISABLE_PREFLIGHT: '1'
  };

  const claude = spawn('claude', [
    '--dangerously-skip-permissions',
    '-p',              // 仅有 -p，无 --continue
    tmpFile
  ], {
    stdio: ['ignore', 'pipe', 'pipe'],
    env: env,
    timeout: 60000     // 60 秒超时
  });

  let stdout = '';
  let killed = false;

  claude.stdout.on('data', (data) => { stdout += data.toString(); });

  claude.on('close', (code) => {
    try { fs.unlinkSync(tmpFile); } catch(e) {}
    if (code === 0) {
      onResponse(null, stdout.trim());
    } else {
      onResponse('Claude错误: ' + code, null);
    }
  });

  // 60 秒超时
  setTimeout(() => {
    if (!killed) {
      killed = true;
      claude.kill('SIGTERM');
      try { fs.unlinkSync(tmpFile); } catch(e) {}
      onResponse('请求超时（60秒）', null);
    }
  }, 60000);
}
```

**问题**：无 --continue 参数，每次调用都是新会话，无法保持上下文。

12.2 SDK 方案代码示例

```javascript
const Anthropic = require('@anthropic-ai/sdk');
const anthropic = new Anthropic({
  apiKey: process.env.ANTHROPIC_API_KEY,  // 'sk-xxxx...'
  baseURL: process.env.ANTHROPIC_BASE_URL  // 可选，自定义端点
});

// 同步调用（非流式）
async function callClaudeSync(messages) {
  const response = await anthropic.messages.create({
    model: 'claude-sonnet-4-20250514',
    max_tokens: 4096,
    messages: messages
  });
  return response.content[0].text;
}

// 流式调用
async function callClaudeStream(messages, onChunk) {
  const stream = await anthropic.messages.stream({
    model: 'claude-sonnet-4-20250514',
    max_tokens: 4096,
    messages: messages
  });

  for await (const event of stream) {
    if (event.type === 'content_block_delta') {
      onChunk(event.delta.text);
    }
  }
}

// SSE 流式响应封装
async function callClaudeSSE(messages, res) {
  res.writeHead(200, {
    'Content-Type': 'text/event-stream',
    'Cache-Control': 'no-cache',
    'Connection': 'keep-alive'
  });

  const stream = await anthropic.messages.stream({
    model: 'claude-sonnet-4-20250514',
    max_tokens: 4096,
    messages: messages
  });

  try {
    for await (const event of stream) {
      if (event.type === 'content_block_delta') {
        res.write('data: ' + JSON.stringify({
          type: 'chunk',
          content: event.delta.text
        }) + '\n\n');
      }
    }
    res.write('data: ' + JSON.stringify({type: 'complete'}) + '\n\n');
  } catch (err) {
    res.write('data: ' + JSON.stringify({type: 'error', message: err.message}) + '\n\n');
  }
  res.end();
}
```

十三、方案选型分析：为什么选择 Claude CLI 而非 SDK
================================================================================

13.1 选择 Claude CLI 的主要原因

| 因素 | Claude CLI | SDK (HTTP API) |
|------|-----------|-----------------|
| 上下文保持 | 通过 --continue 自动保持上下文 | 需手动管理 messages 数组 |
| 会话状态 | Claude CLI 自动维护 .claude 目录 | 需自行实现会话存储 |
| 工具调用 | 原生支持文件读取、代码执行等 | 需自行实现 tool use |
| 认证方式 | 配置文件管理，环境变量自动读取 | 直接传递 API Key |
| 调试便利 | TUI 交互模式，可直接测试 | 需通过代码调试 |
| 容器兼容 | Hermit-Claw 容器预装 Claude CLI | 需额外安装 SDK |

13.2 SDK 方案的优势

- 更精细的控制（temperature、top_p 等参数）
- 适合纯 API 调用场景
- 适合需要完全自定义请求/响应格式的场景
- 更轻量（不需要完整 Claude CLI 功能）

13.3 CLI 方案的优势

- 开箱即用的上下文管理和会话状态
- 内置工具支持（文件操作、代码执行、网页抓取）
- 与 Claude Code 共享配置和状态
- 适合 Agent 场景，需要 AI 自主操作文件系统
- Hermit-Claw 容器环境天然支持

13.4 迁移建议

如果未来需要从 CLI 迁移到 SDK，需要：

1. **会话管理**：自行实现 messages 数组持久化
   ```javascript
   // 需要存储对话历史
   const sessionStore = {
     sessions: {},  // sessionId -> messages[]
   };
   ```

2. **工具调用**：使用 SDK 的 tool use 功能
   ```javascript
   const response = await anthropic.messages.create({
     tools: [
       {
         name: 'read_file',
         description: '读取文件内容',
         input_schema: {
           type: 'object',
           properties: {
             path: { type: 'string' }
           }
         }
       }
     ],
     messages: messages
   });
   ```

3. **错误处理**：统一处理 rate limit、timeout 等
   ```javascript
   try {
     const response = await anthropic.messages.create({...});
   } catch (error) {
     if (error.status === 429) {
       // rate limit 处理
     } else if (error.status === 500) {
       // 服务端错误
     }
   }
   ```
